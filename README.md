# DigiNeeds — GitHub Pages starter site

A lightweight, responsive static website for the DigiNeeds pilot.

## Files

- `index.html` — main page
- `styles.css` — responsive styling
- `script.js` — small mobile-menu/year script
- `assets/digineeds-logo.png` — supplied DigiNeeds logo

## Before launch

1. Replace the WhatsApp number in `index.html`.
2. Replace `hello@yourdomain.co.za` with the real email address.
3. Review service prices and wording.
4. Add your final domain when purchased.
5. Add your final privacy/terms links once those documents are ready.

## GitHub Pages

Create a GitHub repository, upload these files to the repository root, then go to:

Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.

GitHub will give you a temporary `github.io` address. Once you buy your domain, add it under the Pages custom-domain setting and update the domain's DNS records according to GitHub's instructions.
